Place the client's images here.

Default filenames:

logo.png
owner.jpg

If you use different filenames, update these two values in data.js:

businessLogo: "assets/images/your-logo.png"
ownerPhoto: "assets/images/your-photo.jpg"

Recommended:
- Logo: transparent PNG or high-quality JPG/WEBP
- Owner photo: clear portrait, preferably square
